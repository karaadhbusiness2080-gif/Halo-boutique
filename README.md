# HALO BOUTIQUE

Premium underground streetwear from Algeria.

## Build & Deploy

This is a [Vite](https://vitejs.dev) + React + TypeScript project.

### Build settings for Cloudflare Pages

- **Build command:** `npm run build`
- **Output directory:** `dist`
- **Node version:** 18+

### Local development

```bash
npm install
npm run dev
```

### Customize your store

- **Store config** (WhatsApp number, Instagram, TikTok, email, shipping fees): `src/lib/config.ts`
- **Products** (names, prices, images, sizes, colors): `src/lib/products.ts`
- **Product photos:** Replace placeholder image URLs in `src/lib/products.ts` with your own photos placed in `public/products/`
